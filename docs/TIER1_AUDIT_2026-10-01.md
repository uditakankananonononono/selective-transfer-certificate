## Source-grounded discrepancies

Pinned `calPerformance.py` creates a 2,000-cell subsample but uses it only for
edistance, wasserstein, mean_var_distribution and sym_kldiv. PCC and MSE use all
cells. Each unit's performance is rounded to four decimals. The preregistration's
subsampling shorthand is inaccurate for the selected primary/secondary metrics.
A dated clarification is requested before scoring; nothing is silently changed.

Source: https://github.com/bm2-lab/scPerturBench/blob/698f8ff5ed19530bff171e4205be9b42a46a769d/Cellular_context_generalization/o.o.d./calPerformance.py

The old generic grouped-means helper reads all groups. It must not be used as a
pre-score extraction boundary. New `extract_fold` selects allowed row indices
before reading X: all training-context cells and target-context controls only.
Its guarded-matrix test fails upon any target-treated row read. In LOCO, a context
is necessarily training data for other folds; training use is authorized by the
frozen design, but no method-outcome comparison is made until every fold locks.
